01Position // where I stand
▲ what draws me to it

I like patterns and I like solving problems. Security gives me both: to protect a system, you first have to understand how it really works and how it breaks.

What I enjoy most is the process: testing, reading, connecting the dots, until the answer finally makes sense.

◆ what I want to contribute

I want people to feel safe using the technology they depend on every day. For me that means software that respects their data and holds up when someone tries to break it.

That is why I work on tools that catch flaws before software ships, and why I study the cryptography that keeps information private.

03Case Files // security work · 6 entries
CASE-001 flagship open source · apache-2.0

SecDojo Scanner: SAST for C & Rust

A CLI that unifies C/C++ and Rust security tooling (Cppcheck, Flawfinder, Semgrep, cargo-audit, cargo-geiger and Clippy) under a single command, normalising their heterogeneous outputs into one SARIF 2.1.0 report for GitHub Code Scanning. Finding deduplication, a common severity scale and CI/CD-ready exit codes let it run in a pipeline and stop a build when it finds a problem.

SASTC / C++Rust SARIF 2.1.0DockerCI/CD
