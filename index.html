01Position // where I stand
▲ the problem

Governments keep building the same surveillance architecture they would never accept pointed back at them: cameras with no warrant, retention with no expiry, correlation across sources nobody ever agreed to link. It arrives through the infrastructure everyone has to use anyway.

It is rarely a conspiracy. It is just the cheapest architecture to build, rolled out one contract at a time, and almost nobody is ever asked to approve it.

◆ what I do about it

I build the walls. Every camera, sensor and "lawful intercept" is software first. It is written by people, runs on hardware, and is defended by someone or by no one at all. That is where I work.

So I write the scanners that catch the flaws before they ship, study the cryptography built to survive whoever intercepts it today and decrypts it in ten years, and treat privacy as something you engineer in, not bolt on after the break-in.

CASE-001 flagship open source · apache-2.0

SecDojo Scanner: SAST for C & Rust

A CLI that unifies C/C++ and Rust security tooling (Cppcheck, Flawfinder, Semgrep, cargo-audit, cargo-geiger and Clippy) under a single command, normalising their heterogeneous outputs into one SARIF 2.1.0 report for GitHub Code Scanning. Finding deduplication, a common severity scale and CI/CD-ready exit codes make it drop-in for pipelines: the flaw gets caught in review, not in the wild.
